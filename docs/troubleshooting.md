# Troubleshooting & Maintenance Guide

---

## 1. XRDP & Remote Desktop Issues

### Black Screen on XRDP Login
* **Cause**: DBus session conflicts or improper window manager startup scripts.
* **Fix**: Ensure `/etc/xrdp/startwm.sh` cleanly unsets DBus and starts XFCE4:
  ```bash
  unset DBUS_SESSION_BUS_ADDRESS
  unset XDG_RUNTIME_DIR
  exec startxfce4
  ```
  And verify `/root/.xsession` contains:
  ```text
  xfce4-session
  ```

### Chrome Refuses to Launch as Root
* **Symptom**: `Running as root without --no-sandbox is not supported`.
* **Fix**: Ensure `--no-sandbox` is included in the launcher flags. All launchers generated by `vps-chrome-proxy` automatically include this flag.

## 2. Proxy Service Checks

### Checking Xray Service Status
```bash
systemctl status xray-client-us.service --no-pager
journalctl -u xray-client-us.service -n 50 --no-pager
```

### Checking Listening Ports
```bash
ss -tulpn | grep -E '2080|2081|18080|3389'
```

### Testing Connectivity Manually
```bash
# Test through local HTTP proxy
curl -s -m 8 -x http://127.0.0.1:2080 https://api.ipify.org

# Test native connection
curl -s -m 8 https://api.ipify.org
```
